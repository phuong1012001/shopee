## How to create a migration

1. Open `Package Manager Console`
2. Select default project: `Infrastructure`
3. Run: `Add-Migration <MigrateName> -Context ShopeeDbContext -OutputDir DataAccess\Migrations`
4. Add `// <auto-generated>` on top of the generated migration file to suppress the "using directive" warning.

## How to update database

1. Set `Shopee.API` as default startup project.
2. Configure the correct connection string in `appsettings.json` in `Shopee.API` project.

### Method 1:

3. Open `Package Manager Console`:
4. Select default project: `Infrastructure`
5. Run: `Update-Database -Context ShopeeDbContext -OutputDir DataAccess\Migrations`

### Method 2:

3. Set environment `AutoMigration=true` in `appsettings.json` or `appsettings.Development.json` in `Shopee.API` project

## How to delete a migration

1. Open `Package Manager Console`.
2. Select default project: `Infrastructure`.
3. Run: `Remove-Migration -Context ShopeeDbContext -OutputDir DataAccess\Migrations`
